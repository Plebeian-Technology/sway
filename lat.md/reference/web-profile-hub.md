# Web Profile Hub

The web Profile Hub (`app/frontend/pages/Profile/Hub.tsx`) centralizes account management, linking scattered settings into a single surface.

## Architectural role

The Hub acts as an Inertia page aggregating links and surfacing account-level actions:

* Address updates
* Passkey management
* API keys (for allowlisted users)
* Session management (sign out of all devices)
* Account deletion
