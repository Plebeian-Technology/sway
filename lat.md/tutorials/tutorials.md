# Tutorials

Guided walkthroughs for someone new to the codebase, each following a real path through the running system rather than describing one.

- [[trace-a-vote]] — follow one vote from the tap that casts it to the agreement figure on a legislator's page

## What you will end up with

By the end you will have a first-hand map of the request-to-score path, and the habit of looking for a page's data contract in its controller rather than in a fetch call.

1. Read [[system-shape]] first, for the Inertia model everything else assumes.
2. Work through [[trace-a-vote]] with the named files open.
3. Keep [[domain-entities]] open afterwards as the working map.
