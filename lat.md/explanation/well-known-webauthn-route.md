# WebAuthn well-known route

The WebAuthn related-origin document is a route because its response depends on the request host.

## Why the WebAuthn metadata is selected at request time

The `/.well-known/webauthn` response is generated by [[app/controllers/well_known_controller.rb#WellKnownController#index]], which checks the requested host before returning related origins.

A static file could not make that host decision. The host list includes both `sway.vote` and `app.sway.vote`; the response is not limited to the app subdomain. The allowed hosts and returned related origins belong to the controller. Passkey ceremony origins and the relying-party host are separate settings described by [[settings-groups#Settings groups#Why the webauthn group binds one shared prefix]].
