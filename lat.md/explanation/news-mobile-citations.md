# Mobile summary citations

Native bill summary surfaces render in-prose Markdown citations as interactive, accessible links with URL scheme validation.

## In-prose citation parsing

Plain-language bill summaries generated by Sway contain in-prose Markdown hyperlinks to official bill records and local news coverage.

News testimony parses these links without a Markdown library to avoid bundle bloat and React 19 compatibility issues; the summary and position surfaces use [[mobile-markdown-rendering]] instead. The lightweight token scanner decomposes summary text into plain text chunks and link tokens, preserving balanced parentheses in citation URLs.

## Citation URL safety validation

Outbound citation URLs undergo scheme verification before opening external browser sheets.

Only `https:` and `http:` protocols are accepted as safe citation schemes. Potentially unsafe protocols such as `javascript:`, `file:`, `data:`, `intent:`, and `vbscript:`, as well as URLs embedding user credentials, are refused. Unsafe citations render as inert text nodes without accessibility link roles or press handlers.

## Atomic link boundary preservation

Preview truncation preserves boundary-crossing links intact to avoid breaking Markdown syntax into corrupt text fragments.

When a summary exceeds the 200-character preview threshold, string slicing across Markdown syntax would bifurcate link anchors or URLs. Slicing on visible character counts and retaining boundary-crossing link tokens keeps citations interactive in both collapsed preview and expanded states.
