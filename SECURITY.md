# Security policy

## Reporting a vulnerability

Email [security@sway.vote](mailto:security@sway.vote). Do not open a public issue: Sway holds voters' phone numbers and home addresses, and a public report puts them at risk before a fix exists.

Include what you found, where (URL, endpoint, file or app screen), how to reproduce it, and what an attacker could do with it. Attach a proof of concept if you have one.

We will acknowledge your report, keep you informed while we work on it, and credit you in the fix if you want that.

## Scope

- The web app at sway.vote and app.sway.vote
- The Sway mobile app
- This repository

## Please avoid

- Reading or changing data that is not yours
- Denial of service, spam or social engineering
- Testing against other people's accounts

## Supported versions

Only the code on the default branch is supported. Production runs the latest deploy of it.
